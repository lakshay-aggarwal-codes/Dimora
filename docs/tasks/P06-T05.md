## Behaviour
- URL `radius=5|10|25|50` (km) next to `dest`. Needs a valid destination; any other value, a repeated or object value, or no destination gives a plain message beside the form and the radius is ignored (the rest of the search still works).
- **Centre**: the average of the public points of the published stays that match the destination text (the same match as the destination box: city/state/country prefixes). It comes from our own data, not from a geocoder: a geocoding call per public search would cost money and Mapbox's temporary mode does not allow keeping results (ADR-007).
- **Filter**: `publicGeometry: { $geoWithin: { $centerSphere: [[lng, lat], km / 6378.1] } }`. The circle replaces the destination text match, so "Goa within 25 km" also finds stays in nearby towns. Built once in `listingFilterFor`, so the results page, the count and the map data (`/api/search/map`) agree.
- No stay to centre on (unknown destination): the ordinary text search runs (finds nothing) and no circle is used.
- UI: a "Distance around the destination" select in the filter panel; chip "Within N km" (removing it keeps the rest); counted in the filter badge and cleared by "reset filters"; saved searches keep it (`ORDER` in `searchUrl.js`).
- Empty search with a radius: suggestion "Search only <dest> itself, not N km around it"; the other "remove this filter" counts keep the circle; removing the destination also removes the radius.

## Privacy
Only `publicGeometry` is read (never `geometry`); results show no new coordinates. Because that point is 300-800 m from the real one, a stay near the circle's edge can be on the wrong side; 5 km is the smallest circle.

## Limits
- One extra aggregate per radius search (no cache). With a few thousand stays this is cheap; revisit in P18-T02.
- The average ignores the antimeridian and is pulled by outliers (a far-away stay with the same city name); fine for the Indian market this app targets.
- No "near me" or free place name: the centre is always derived from a destination already in the data.
