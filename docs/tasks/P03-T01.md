## Design decisions
- Palette (all contrast values are measured by the test): ink on sand 13.9:1, muted text on sand 6.7:1, white on teal 6.3:1, white on accent 5.6:1, teal text on sand 5.9:1, orange on sand 5.2:1; UI: strong border 4.2:1 on sand, star 4.4:1.
- Teal is the brand/link/focus colour; the burnt orange is the single accent used for the search button and the main form buttons. Prices will use it when P04/P08 redo those views.
- Dark mode is not implemented: `color-scheme: light` and a commented hook in `tokens.css` showing where the semantic layer would be redefined.
- Typeface unchanged (Plus Jakarta Sans), now with a system fallback stack.
