# P06-T03 - Detail-page map (Q41)

Deps: P06-T02 (done, Q40), P01-T06 (done, Q10).

## What changed
- `public/js/map.js`: rewritten. Draws a circle (fill + outline) around the listing's public point instead of a pin. The ring is 64 great-circle points at `data-radius` metres (default 1000; values outside 100-5000 are ignored), longitudes unwrapped so a circle across the antimeridian stays one ring. The view is fitted to the circle. Zoom buttons added (no compass). No `Marker`, no `Popup`.
- Failure handling: the server-rendered text inside `#map` stays for no-JS; JS puts it back (with "The map could not be loaded.") when Mapbox GL or the token is missing, the constructor throws, an `error` event fires before the first `load` (offline, blocked style, bad token), or the map has not loaded within 10 s. Errors after load (a single tile) are ignored.
- `views/listings/show.ejs`: map section now has a screen-reader description (`#map-description`), `#map` is `role="region"` with `aria-label` and `aria-describedby`, `data-radius`, the fallback text, and a visible "Exact location shared after booking." note.
- `src/utils/geo.js`: `PUBLIC_AREA_RADIUS_M = 1000` (exported). `src/controllers/listing.js` passes it as `mapRadius`.
- `public/css/base.css`: styles for the fallback text.
- Tests: `tests/unit/mapScript.test.js` rewritten (18 cases), one case added to `tests/integration/listings.show.test.js`, one to `tests/unit/geo.test.js`.

## DB / config changes
None. No migration, no new env key, no new dependency. The CSP already allows Mapbox GL, tiles and workers.

## Acceptance
- A circle, not a pin; the circle (1000 m) always contains the real home (offset is 300-800 m) and is centred on the public point, so the page source still has no precise coordinates and no street address.
- Text "Exact location shared after booking" is visible; keyboard/ARIA description present; text fallback when the map cannot load.

## Limitations
- Never seen in a browser. Radius is the same for every listing. Text-only fallback (no static image: it would need another Mapbox call and a token in an image URL).
- The draggable host pin (P04-T04 enhancement) and the search map (P06-T04) are separate.

## Owner steps (browser, needs your public token)
1. Run `npm test` and `npm run lint` once.
2. Open a listing detail page: a teal circle about 2 km across, no pin, zoom buttons work, Tab reaches the map and the screen reader reads the description.
3. Open DevTools > Network > Offline, reload: the text "The map could not be loaded. Approximate area: ..." appears instead of a blank box.
4. View page source: no precise coordinates, no `address.line1`.
