# P06-T01 — Map provider decision and token split (Q18)

Date: 2026-10-15 · Deps: P01-T01 (done)

## Outcome
Decision: **keep Mapbox**, two tokens (ADR-007, status Accepted). Most of the split already existed (`MAPBOX_SERVER_TOKEN` used only by `src/services/geocoding.js`; `MAPBOX_PUBLIC_TOKEN` exposed as `mapPublicToken` -> `data-token`). This task adds enforcement, a test of the acceptance criterion, and the documented decision.

## Files changed
- `src/config/env.js` — error in production / warning elsewhere when server and public token are identical; new optional `MAPBOX_GEOCODING_PERMANENT` (boolean, default false) exposed as `config.mapbox.permanentGeocoding`.
- `src/services/geocoding.js` — passes `mode: "mapbox.places-permanent"` only when that switch is on.
- `.env.example` — comments for both tokens, new optional key.
- `docs/ADR/007-maps-provider.md`, `docs/ADR/README.md`, `docs/PROGRESS.md`, this file.
- Tests: `tests/integration/mapbox.tokens.test.js` (new: detail page, login page, 404 contain no server token; public token present), `tests/unit/env.test.js` (identical tokens, new key; legacy-warning count 6 -> 7 because `MAP_TOKEN` now also triggers the shared-token warning), `tests/unit/geocoding.test.js` (permanent mode), `tests/helpers/config.js` (new field).

## DB / config
No DB change. New optional env key `MAPBOX_GEOCODING_PERMANENT`. No dependency change.

## Limitations / owner checklist
1. **Official limits not verified.** The sandbox could not open mapbox.com; the numbers in ADR-007 (50,000 GL JS loads, 100,000 temporary geocoding requests, permanent geocoding with no free tier) come from third-party summaries. Open https://www.mapbox.com/pricing and the Mapbox terms, confirm, and edit the "Verification status" section.
2. In the Mapbox account create (a) a secret token with only the geocoding scope for `MAPBOX_SERVER_TOKEN`, (b) a public `pk.` token with URL restrictions (your production domain and `http://localhost:*`) for `MAPBOX_PUBLIC_TOKEN`. Put both in `.env`, remove the old `MAP_TOKEN`. Revoke the old shared token if it was ever public (it was shipped to every browser).
3. Load a listing page, view source: only the `pk.` token must appear.
4. Decide on `MAPBOX_GEOCODING_PERMANENT` for any public deployment (ADR-007, "Storage of geocoded coordinates"). Leave it off unless your account may use permanent geocoding, otherwise listing saves fail with "temporarily unavailable".
