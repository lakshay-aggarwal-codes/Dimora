## Definitions (also on the page)
Confirmed and completed stays only. Earnings = nights + weekend nights + cleaning (the host's lines), counted in the month the stay starts. Nights booked = nights of those stays inside the range. Occupancy = nights booked / (days in range - blocked nights). Estimates: nothing is paid out (ADR-009).

## CSV columns
`listing, listing_id, status, period_first_day, period_last_day, bookings_started, nights_booked, nights_blocked, nights_available, occupancy_percent, earnings_estimate, currency` - UTF-8 + BOM, CRLF, one line per listing. Cells starting with `= + - @` or a tab/return get a leading apostrophe so a spreadsheet will not run them.

## Limitations
- Up to 50 listings and 5000 stays per report (a note appears if cut).
- A listing is measured for the whole range even if published part-way through; blocks removed later are not remembered.
- Per-listing only; no per-booking export, no charts.
