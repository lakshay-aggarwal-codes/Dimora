1. `npm run dev`. On `/listings` press Tab once: "Skip to main content" appears; Enter moves past the navbar to the page.
2. Keep pressing Tab through the header: brand, Explore, search field, Search, Dimora your home, Sign up, Log in. All show a teal focus outline.
3. Resize to 360 px: the menu button opens/closes with Enter/Space and `aria-expanded` flips (dev tools > Elements).
4. Log in: the bell and the username button are reachable by Tab; Enter on the username opens the menu, Arrow keys move, Esc closes, Logout works.
5. Screen reader (NVDA, free): the flash message after logging in is read aloud; the page title in the tab differs on every page.

## Limitations / deviations
- Interactive behaviour (dropdown, collapse) comes from Bootstrap's script and is not exercised by Jest.
- The account menu is short on purpose: it will gain "Profile" and "My listings" when those pages exist; no dead links were added.
- The notification bell is a placeholder with no behaviour (P11-T01 replaces it).
- Meta description is the same default text on pages without their own; `noindex` for private pages and Open Graph tags are P18-T05.
- Nav text changed from "Sign Up"/"Login" to "Sign up"/"Log in". Page headings such as "Login on Dimora" are unchanged (P03-T04/T05).
