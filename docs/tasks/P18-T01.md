## What changed for a visitor
- Cards: before, the card used the stored original photo, whatever its size. Now 800 px (`f_auto,q_auto`), with 400/800/1200 px candidates so phones take the small one; below-the-fold cards load lazily.
- Detail page: the first photo loads at once with high priority; thumbnails load lazily.
- Every picture reserves its space (`width`/`height`), so the page does not jump while pictures arrive.

## Deviations and limits
- "Blurred placeholders (optional)": not done.
- Unsplash seed photos are resized with Unsplash's own parameters in `srcset` only; their `src` stays the plain address (older tests pin it). Photos from other hosts (for example imported `a0.muscache.com` pictures) are not resized: their hosts' resizing rules were not checked.
- Cloudinary creates each new size the first time it is asked for, so the first visit to a size is slower, and transformations count against the Cloudinary plan (not verified here).
- `sizes` assumes the card grid is 1/2/3 columns at 768 and 992 px: if the grid changes, update `listing-card.ejs`.
