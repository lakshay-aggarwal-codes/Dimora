## Signature #2 metric (render < 1 s): NOT measured
Needs the app and the seeded database. To measure locally (PowerShell), with 4 real listing ids:
```powershell
Measure-Command { Invoke-WebRequest "http://localhost:3000/compare?ids=ID1,ID2,ID3,ID4&in=2026-12-01&out=2026-12-04&guests=2" -UseBasicParsing } | Select-Object TotalMilliseconds
```
Run it three times; the first run includes warm-up. Cost per request: one `find` for 4 listings plus 4 quotes in parallel (one ledger query each).

## Deviations / limits
- "Book" opens the listing page; that page does not read `?in&out` yet, so the guest re-enters dates there.
- "Fees %" = cleaning + service fee as a share of the total (tax excluded), one decimal.
- The distance uses the stay's approximate public point (about 300 to 800 m off), so it is labelled "about".
- A stay that is not public (draft, hidden, deleted, unknown id) shows as "No longer available" with no title, so a draft's title never leaks.
- Mixed currencies: message and a list of links, no table (multi-currency pricing is not supported yet).
- Distance row needs a place typed in the form; there is no map picker.
