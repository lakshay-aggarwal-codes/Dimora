# P04-T07 - Public listing detail redesign (Q33)

Date: 2026-10-17 - Deps: P04-T03 (Q28) and P03-T04 (Q25), both present. Built on the repo that includes Q29 (uploaded zip) and Q30; **Q31 (P04-T04) and Q32 (P04-T06) were not in what I had**, and this task does not depend on them. No dependency, env key or migration.

## What changed
| File | Change |
|---|---|
| `views/listings/show.ejs` | New sections, each with a labelled heading: key facts (guests, bedrooms or "Studio", beds, bathrooms; icons are decorative), the type line (room and property type) and a rating summary linking to the reviews, "About this place", host card, "What this place offers" (amenities grouped), "Things to know", the booking slot in the price panel, the location text above the map, a review summary. Sections with no data are left out (no empty headings, no "undefined"). Host-only controls, the preview and draft banners from P04-T05 are unchanged. |
| `src/controllers/listing.js` | A draft, unpublished, deleted or missing listing, and an id that is not an ObjectId (no database call), now give the normal **404 page**; they used to redirect to `/listings` with a message. Passes `ratingSummary`, `amenityGroups`, `facts` (type/room/cancellation labels) and `structuredData` (only for a public page, never for a host's draft or a preview). |
| `src/utils/amenities.js` | `groupAmenities(keys)`: fixed group order, labels not keys, duplicates and unknown keys dropped. |
| `src/utils/ratings.js` | `summarizeRatings(reviews)`: average with one decimal and count; only whole ratings 1-5 count. |
| `src/utils/structuredData.js` | `listingJsonLd` / `safeJson`: schema.org `LodgingBusiness` with name, description (500 characters), up to 10 images, city/state/country, price range, amenities and an `aggregateRating` only when there are reviews. `<`, `>`, `&` and the line separators are written as `\u` escapes, so a title cannot end the element. The street address and the coordinates are never included. |
| `src/config/constants.js` | Each amenity has a `group`; new `AMENITY_GROUPS` order. The wizard is unaffected. |
| `public/css/components.css`, `tokens.css` | Styles for the new parts; one new size token. |
| Tests | New `detailHelpers` (unit), `listing.detail` (the page with the least and the most data, escaping, JSON-LD, 404 cases); updated `listings.show` (404, not-an-id) and, for the redirect-to-404 change, `lifecycle.views`, `listing.lifecycle.db`, `host.wizard.db`, `listings.crud.db`; `listings.show(.db)` check "Hosted by" instead of "Owned by". |
