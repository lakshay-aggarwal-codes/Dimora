## Deviations / limits
- Roadmap says "20 lists": defined as `LIMITS.maxLists`, enforced when P10-T02 adds list creation.
- The 100-stay check can overshoot slightly under a burst of parallel requests.
- Unsaving removes the stay from all of the member's lists (only one exists now).
- If the database is not connected, `withSavedIds` skips the lookup and every heart shows empty.

## Manual checks (browser)
1. Signed in, click a heart on `/listings`: it fills without a reload; reload: still filled.
2. Open `/wishlists`: the stay is there. Have its host unpublish it: it shows "No longer available" with Remove.
3. Signed out: the heart links to the login page.
4. Keyboard: Tab reaches the heart, Enter/Space toggles it, focus ring is visible.
5. Turn JavaScript off: the heart still works as a form and returns to the same page with a message.
