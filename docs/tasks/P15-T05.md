## Decisions and deviations
- **No photo evidence.** The card says "optional host photo evidence"; it is optional and needs a link between a photo and a feature that does not exist. Not built; the photo manager's alt text and captions can describe a feature.
- **Filter semantics:** all selected features must be declared (like amenities). A listing that declared nothing never matches, so the filter cannot find places whose host never filled it in; the docs say so.
- **Reporting** reuses the reports system (P12-T04) and its existing reason "Inaccurate or misleading"; no new reason, no new route. Moderation sees an ordinary listing report.
- The search page's map, the comparison workspace and the demo seed do not use the new field.
- Wording "declared" appears in the host form, panel, chips and listing page; the notice never says verified, certified or guaranteed (tested).
