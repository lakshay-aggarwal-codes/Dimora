## Behaviour
- **Queue:** open reports oldest first, closed ones newest-closed first; the tab badge is the number of open reports; unknown `status`/`kind` values fall back to open / all.
- **Closing:** a note of 5 to 500 characters is required for resolve and dismiss; it goes to the audit log (`report.resolve` / `report.dismiss`, target type `report`). The reporter's "My reports" page shows only the status, never the note or the admin. "Also close the N other open reports about this" is an explicit checkbox; without it only this report closes.
- **Hiding a review:** a reason (5 to 500 characters) is required and goes to the audit log (`review.hide`, target type `review`). The review disappears from the listing page and from `ratingSum`/`ratingCount`/`ratingAvg` in the same atomic update; restoring (`review.restore`) puts it back. Two admins at once: one wins, the other is told it is already hidden. Hiding does not delete anything and does not let the guest write another review for the same stay.
- **Redirects:** the hide and restore forms send the id of the report they came from; only a valid id (or nothing) is accepted, so the redirect can only be a report page or the queue (tested with `https://...`, `//host`, `javascript:` and other paths).
- **Refusals** (no note, already closed, already hidden, missing item) flash the message, go back, and write no audit row.
- **Messages:** a message report shows "Messages cannot be opened here yet": messaging (P11) does not exist. When it does, the report page may show only the reported conversation, never the inbox.
- Only admins reach any of it (a member, a suspended admin and a visitor get the ordinary 404). All text from reports and reviews is escaped.

## Limitations
- No notification to the reporter or to the review's author (P11).
- An admin cannot yet edit a review, only hide or restore it.
- The queue has no free-text search and no assignment ("who is looking at this"); two admins can read the same report.
- Restoring a review adds it to the end of `listing.reviews`; the page sorts newest first, so the order shown is not affected.

## Manual checks (owner)
1. As a member, report a review from the listing page; as the admin, open Admin > Reports: the report is in "Open".
2. Open it, hide the review with a reason: the listing page no longer shows it and the rating summary changes; the author's booking page says it is hidden.
3. Restore it: it is back and the rating is as before.
4. Resolve the report with a note and tick "also close the other open reports": the queue count drops by all of them.
5. Admin > Audit log: one row for each action, with your reason.
