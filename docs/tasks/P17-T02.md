## Behaviour change to know about
Any request whose query or form contains a key with `$` or `.`, a prototype name, a NUL byte, more than 8 levels of nesting or more than 5000 values now gets a 400 ("That request contains input we do not accept."). No form of this site sends such keys (checked the form field names in `views/`). If a test or feature sends a key with a dot, it will fail here by design.

## Deviations
