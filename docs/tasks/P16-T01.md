## Manual checks (owner)
1. `npm run dev` with `SIMULATED_PAYMENT_OUTCOMES=true`. Book a listing: you land on "Pay (simulated)" with the TEST MODE banner and no card fields.
2. Choose "Is declined" and press the button: red message, dates still held until the time shown. Press again with "Succeeds": the booking page shows it booked (instant) or sent to the host.
3. Press the button twice quickly: one charge (check `paymentattempts` in Compass).
4. Fail a payment and wait out `PAYMENT_HOLD_MINUTES` (set it to 5): the sweeper (`npm run sweep` or the running job) expires the booking and the dates open up again.
5. Have the host decline a paid request: a `refunded_simulated` record appears once.
