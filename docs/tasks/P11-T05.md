## Limits and deviations
- No one-click `List-Unsubscribe-Post` (CSRF would refuse the provider's POST); the header carries the page URL.
- No counter for the 100-a-day Resend limit; past it sending fails (logged), in-app notifications are unaffected.
- A stop link depends on `SESSION_SECRET`: rotating it invalidates old links.
- Notification types without a group are never emailed (a test checks every event is in a group).
- Messages (P11-T02/T03) do not create notifications in this repo, so there is no "messages" email group.
