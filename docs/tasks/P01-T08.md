# P01-T08 — Test harness (Q8)

Date: 2026-10-14 · Node v22.22.2 · New devDependencies: `jest ^30.5.2`, `supertest ^7.3.1`, `mongodb-memory-server ^11.3.0`

## What changed
- `package.json`: `npm test` → `jest`; new `npm run test:coverage` (text summary + `coverage/lcov-report`, git-ignored and ignored by nodemon/prettier already). The `node --test` runner is no longer used.
- `jest.config.js`: node environment, tests in `tests/**/*.test.js`, `setupFiles` sets `NODE_ENV=test`, `clearMocks`, 15 s test timeout, coverage over `src/**` and `server.js`.
- **External services are always mocked** (`moduleNameMapper`, so no test can call them by accident): `cloudinary` → `tests/mocks/cloudinary.js` (fake `secure_url`/`public_id`, `destroy`; override with `uploader.upload_stream.mockImplementationOnce`), `@mapbox/mapbox-sdk/services/geocoding` → `tests/mocks/mapboxGeocoding.js` (default: one Point; `__setFeatures`, `__noResults`, `__reset`). Import both via `tests/helpers/mocks.js`.
- Helpers:
  - `tests/helpers/db.js`: `describeDb`, `useTestDb()` (starts an in-memory MongoDB per test file, builds indexes, wipes collections after each test, stops it afterwards; hooks allow 180 s for the first binary download). `SKIP_DB_TESTS=1` skips every `describeDb` suite.
  - `tests/helpers/factories.js`: `buildUserData`, `buildListingData`, `createUser` (via passport-local-mongoose, returns `{user, password}`), `createListing`, `createReview`.
  - `tests/helpers/agent.js`: `createTestApp`, `createAgent` (cookie-keeping supertest agent on the real `createApp`, memory session store, silent logger), `login(agent, creds)` through the real form, and `getCsrfToken` — a stub that P01-T10 fills in.
  - `tests/helpers/config.js` (valid frozen test config), `logCapture.js` (pino into memory), `errorApp.js` (from Q7).
- Ported to Jest with no change in what they assert: `env`, `app.smoke`, `errors`, `app.errors`. One assertion switched to `expect().toEqual` because Jest runs tests in a separate realm and `node:assert` deep equality compares prototypes.
- New suites: `tests/unit/mocks.test.js` (mocks are active; upload middleware against the mock, failure path; geocoder), `tests/unit/factories.test.js` (builders pass model validation; a listing without geometry fails), `tests/integration/pages.test.js` (real app and views with `Listing.find` stubbed: index, login/signup pages, anonymous redirect, 404 regression, request id), `tests/integration/auth.db.test.js` (needs MongoDB: factories + wipe between tests, index shows a saved listing, signup hashes the password and logs in, **signup does not log or print hash/salt/password** (P01-T04 regression), duplicate username, login helper and wrong password, bad id with DB connected).
- `eslint.config.js`: Jest globals for `tests/**` and `jest.config.js`. `.gitignore`: `coverage/`.

## Commands
```powershell
npm test                      # everything (first run downloads a mongod binary)
npm test -- --runInBand       # serial
npm run test:coverage
$env:SKIP_DB_TESTS = "1"; npm test    # skip database suites
```
