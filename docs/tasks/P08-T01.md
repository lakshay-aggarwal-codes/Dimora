## The rules `quote` follows
- Nights come from `eachNight` (at most 90, check-out is not charged). A night is a weekend night if it **starts** on a day in `weekendDays` (Friday and Saturday by default); it costs `weekendNightlyMinor` when the listing has one, else the nightly price.
- `lines`, in this order, each with a `code` and `amountMinor` (the view writes the words): `nights`, `weekend_nights` (only when there are such nights), `cleaning` (only if > 0), `service_fee` (only if > 0), `tax` (only if > 0). Tax in an inclusive price has `included: true` and is not added to the total.
- Accommodation = nights + cleaning. Service fee = `percentOf(accommodation, serviceFeeBps)`. Tax base = accommodation (the service fee is not taxed in this illustration). Tax slab = the first whose `upToMinor` is at least the average price per night (`divideRound(subtotal, nights)`).
- Exclusive: `total = accommodation + fee + tax`. Inclusive: `tax = accommodation - accommodation x 10000 / (10000 + rate)` (half up), and `total = accommodation + fee`.
- Refused with `QuoteRefusedError`: a missing, zero, negative, fractional, text or unsafe nightly price; the same for a set weekend price; an invalid cleaning fee (0 and unset are fine); a currency other than the configured one. `ValidationError`: bad dates, check-out not after check-in, more than 90 nights, `guests` not a whole number >= 1. `TypeError` (a bug, not a user message): a date that is not a date-only Date, or a mistake in the config.

## Decisions and limitations
- The numbers (10 % service fee, flat 18 % tax, Friday and Saturday weekends) are placeholders for the product, not facts; change `src/config/pricing.js` only. Indian hotel GST really depends on tariff slabs and host registration; verify before showing it as anything but illustrative.
- No page uses `quote` yet: the quote endpoint and live panel are P08-T02, checkout is P08-T03. Booking rules (min/max nights, guest capacity, notice) are P07-T06; `guests` is validated but does not change the price.
- `lines` carry numbers and codes, not text, so currency formatting stays in the views (ADR-002); a reservation will store the whole quote with `breakdownVersion` (P07-T05).
- Dynamic price rules (P08-T04) will add lines to this same structure.
