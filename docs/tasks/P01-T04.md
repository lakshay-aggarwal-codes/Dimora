## Behaviour changes to be aware of
- `/listings/<bad id>` was a 500 with "Cast to ObjectId failed…"; it is now the 404 page (D-10).
- In production any 500 shows "Something went wrong on our side." plus a reference id; the details are in the server log under the same id.
- Duplicate-key and Mongoose validation failures that reach the handler now return 409 / 400 pages instead of 500.
- Request logs are JSON on stdout (one line per request). Pipe through `npx pino-pretty` locally if you prefer a readable form (not installed by this task).

## Limitations / notes
- No `LOG_LEVEL` setting yet (fixed `info`; `silent` when `NODE_ENV=test`); adding a validated env key is outside this card.
- Express treats `throw null` / `throw undefined` as "no error" and falls through to the 404 page; nothing leaks.
- `InvalidTransitionError` is defined for P07-T05; nothing throws it yet.
- 401 is not a typed error here (login redirects stay as they are); P02/P01-T09 can add one.
