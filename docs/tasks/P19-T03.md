## Limitations
- `TRUST_PROXY_HOPS=1` is not verified for Render; the provider does not document the proxy count and community posts disagree (1 vs 3). The check is in `docs/DEPLOYMENT.md`. Until done, rate limits may be per proxy rather than per visitor.
- Sleeping free instance: first request after 15 idle minutes takes about a minute; sweeper and nearby retry only run while awake (they catch up at start).
- Rolling back code does not undo migrations; migrations must be additive (documented).
- `/healthz` is independent of the database on purpose (Render restarts an instance whose check fails).
- `render.yaml` was only checked by our tests (shape, no secrets, keys known to the app).
