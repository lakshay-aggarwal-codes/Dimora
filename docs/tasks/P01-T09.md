## Decisions
- CSP: `default-src 'self'`; scripts: self + nonce + jsDelivr (Bootstrap) + Mapbox; styles: self + nonce + jsDelivr, cdnjs (Font Awesome), Google Fonts, Mapbox; fonts: Google Fonts files, cdnjs; images: self, data:, blob:, Cloudinary, Unsplash (seed), Mapbox; connect: Mapbox; workers/children: blob: (Mapbox GL); `object-src 'none'`, `base-uri`/`form-action`/`frame-ancestors` self. `style-src-attr 'unsafe-inline'` is kept because Mapbox GL, `error.ejs` and the listing cards use `style=""` attributes (cleanup in P03-T01); `script-src-attr 'none'`.
- Referrer policy is `strict-origin-when-cross-origin`, not helmet's `no-referrer`, because Mapbox public tokens can be restricted by URL.
- Only failed logins count towards the limit (`requestWasSuccessful: req.user`), so shared networks are not locked out by normal use. Counters are in memory per process (fine for one instance; use a store when scaling out).

## Owner steps
1. `npm install` (updates `package-lock.json`; commit it), then `npm test`, `npm run lint`.
2. `npm run dev`: open `/listings` and a listing detail page with DevTools open. The console must show no CSP violations; the map, Bootstrap, icons and fonts must load. Paste any violation text.
3. Log in, click Logout (button in the navbar); open `/logout` by URL: 404 page.
4. Try 6 wrong passwords at `/login`: the 6th shows "Too many requests".
5. Production-like check (optional): behind HTTPS, the session cookie shows Secure/HttpOnly/SameSite=Lax.

## Limitations
- No CSRF token yet (P01-T10); the logout POST is protected only by `SameSite=Lax`.
- `connect-flash` writes to the session on every request, so every visitor still receives a session cookie.
- `secure` cookies mean a production-mode run over plain http cannot log in; run production behind HTTPS.
