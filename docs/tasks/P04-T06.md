## Decisions
- Publish is offered in the list only when the checklist is complete; otherwise the row links to the status page, where each missing item has a fix link. A draft goes back to the wizard ("Continue").
- Delete stays on the status page (it needs the confirmation dialog); the list has no delete button.
- Suspended listings (set by a moderator, P14-T03) show only the status link.
- Every listing is shown in one table, 100 at most; paging is not needed at this size.
